# Baccha birthday surprise

## Publish on GitHub Pages
1. Create a new GitHub repository and upload everything in this folder (index.html, images, audio, .nojekyll).
2. Settings > Pages > Deploy from a branch > main / root > Save.
3. Your site goes live at https://YOUR-USERNAME.github.io/REPO-NAME/

## Before you share the link
- **Song:** `audio/shaky.mp3` is included and plays automatically after the PIN is entered.
- **Replies:** replies are emailed to bikeshpower3@gmail.com through FormSubmit. After publishing, send one test reply yourself, then open the FormSubmit activation email in that Gmail inbox and click Activate. Replies only arrive after that one-time step.
- **PIN:** 3515 (change it in the CONFIG block in index.html).
